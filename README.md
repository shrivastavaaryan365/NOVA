# NOVA

A responsive landing page concept for a digital agency. NOVA presents web design and digital product services through a modern, interactive single-page website.

## Features

- Single-page layout with Home, About, Services, and Contact sections
- Responsive styling for different screen sizes
- Interactive hero section with a pointer-responsive dot animation
- Smooth scrolling and reduced-motion support
- NOVA logo graphic that toggles between “NOVA” and “Innovation”

## Built with

- HTML
- CSS
- Vanilla JavaScript
